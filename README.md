# Interactive Digital Experience

A personal interactive website created to capture meaningful moments through design, animation, and storytelling.

The project explores how frontend technologies can be used to transform personal moments, memories, and emotions into an engaging digital experience.

## Features

- **Interactive Landing Page** – A personalized introduction.
- **Memory Gallery** – A visual collection of memorable moments.
- **Interactive Timeline** – Highlights of important moments.
- **Final Surprise Section** – A personalized closing experience.
- **Responsive Design** – Adapted for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Anime.js

## Purpose

This project was developed as a creative frontend experiment, focusing on interactive storytelling, animation, responsive layouts, and user experience.
